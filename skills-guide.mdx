A BrowserPair Skill is a reusable, versioned guide for a repeatable browser task. It describes **how to work**, not **what the browser is allowed to do**.

<Warning>
  Skills never grant new websites, tools, access to protected values, approvals or browser ownership.
</Warning>

## How to use Skills

<Steps>
  <Step title="Create a Skill">
    Open **Skills** in the BrowserPair App, describe the workflow and save it. Keep private data and credentials out of the definition.
  </Step>
  <Step title="Review and version it">
    Maintain your own Skills and versions. Imported or shared Skills must be reviewed before use.
  </Step>
  <Step title="Choose only when needed">
    You can explicitly choose an applicable Skill when starting a task. Connected agents can optionally search for and read available Skills when their work would benefit.
  </Step>
  <Step title="Check the result">
    The task still uses current page observations, normal browser permissions and evidence-based verification.
  </Step>
</Steps>

**Skills are not automatically matched to every task.** BrowserPair does not insert a Skill lookup or a separate model call into the default task flow. Without a Skill, tasks work normally.

## Optional connected-agent tools

Where the connected client supports them, the Remote MCP interface provides:

| Tool | Purpose |
| --- | --- |
| skill_search | Find applicable visible Skills when the agent decides they are useful. |
| skill_read | Read one Skill's current instructions. |
| skill_create | Create a new private Skill under the owner's account. |
| skill_update | Save a new version of an owned Skill. |
| skill_delete | Retire an owned Skill. |

An agent can explicitly attach an available Skill and version when starting a task. The selected instructions cannot change the account's Standard or Developer mode or bypass task confirmations.

## Good Skill content

Keep applicability, required inputs, suggested steps, expected output, verification, limitations and recovery instructions explicit. Never save passwords, tokens, customer records or private page contents as reusable instructions.
