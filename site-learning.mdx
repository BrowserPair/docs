**Site Learning has been retired.** BrowserPair no longer offers the former automatic site-pattern learning and shared site-knowledge settings.

The former **Automations → Learning** instructions, exclusions, learned-site library, and sharing opt-in described in older material do not apply to the current product.

If you want an agent to reuse a workflow, use [Skills](/skills-guide). Skills are optional instructions selected by the user or agent; they do not grant permissions and do not automatically collect website activity.

For questions about browser observations and retention, see [Browser sessions and data flow](/browser-session-data-flow), [Permissions](/permissions) and the [Privacy Policy](https://browserpair.com/privacy/).
