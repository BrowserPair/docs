Developer mode controls **when BrowserPair asks you** before sensitive steps. It applies account-wide to ChatGPT, Claude, other MCP connections, API keys, BrowserPair Chat and schedules. It is not a temporary grant to one agent.

<Warning>
  Developer mode starts with all nine **Ask me before** switches off. Activate it only if you trust every connected AI agent on your account.
</Warning>

## Standard compared with Developer

| Sensitive step | Standard defaults | Developer defaults |
| --- | --- | --- |
| Payments; sign-in/account security; deletion; sending/publishing; files; passwords/secrets; website instructions | Ask before acting | No additional question by default |
| Opening new websites; submitting forms | No question by default | No question by default |
| Custom ask-before switches | Any switch can be changed | Any switch can be changed |
| Browser and task protections | Always enforced | Always enforced |

Both modes offer the same browser tools. Chrome site access, managed-browser blocks, task-required confirmations, user-entered credentials, local file choice, generation checks and uncertain-effect recovery remain enforced in both.

## Switch modes

<Steps>
  <Step title="Open Permissions">In the [BrowserPair App](https://app.browserpair.com/), open **Manage → Permissions**.</Step>
  <Step title="Use Developer">Choose **Developer → Use**, acknowledge the warning, and review every ask-before switch.</Step>
  <Step title="Return to Standard">Choose **Standard → Use** to restore its default questions. Changes affect future and pending decisions, not completed website actions.</Step>
</Steps>

There is no per-agent Developer timer, per-key permission preset, connected-app website editor or reusable agent-specific sensitive-data grant.

## Sensitive data and manual steps

Sensitive data is normally masked in Standard mode. The current task agent may request one protected category at a time; the current account **Passwords and secrets** question determines whether that request needs additional approval. The task and browser boundaries still apply.

A task may pause for you to sign in, verify an account, review a payment or select a local file yourself. Developer mode never bypasses these user steps or permits blind replay of an action with an uncertain effect.

## For agent developers

Read the active mode and current ask-before settings from task guidance. Do not rely on removed per-agent `expires_at` values or time-limited grants. A `sensitive_category` request is bounded to the current observation and task. See [Permissions](/permissions) and [Sensitive access](/sensitive-access).
