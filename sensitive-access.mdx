BrowserPair observes pages through the extension in your connected Chrome profile. Protected fields are masked in ordinary page observations in both Standard and Developer modes. Connecting an AI agent does not automatically disclose passwords, codes, card numbers or tokens.

## Requesting protected data

Sensitive fields are masked by default. A protected-data request is possible only if the current connection explicitly supports it and the owner authorizes that disclosure. Not every AI app offers this option; ChatGPT connections do not provide a protected-data observation request. Complete any unsupported sensitive step yourself in Chrome. Switching to Developer does not force a client to receive protected values. Browser identity, task intent, Chrome policy and required task confirmations remain in force.

## Manual steps remain yours

When a website requires sign-in, verification, a payment review or a local file choice, BrowserPair can pause for you to complete that step. Neither mode bypasses required manual input or permits blind replay of an uncertain effect.
