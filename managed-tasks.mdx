Use **Chat** in BrowserPair when you want to plan and run a task with an Agent Model you configure. If you connect ChatGPT, Claude or another AI app through Remote MCP, you can instead start tasks there without configuring a managed Agent Model.

## Before your first task

<Steps>
  <Step title="Pair your browser">Connect the Chrome profile you want BrowserPair to use.</Step>
  <Step title="Connect an Agent Model">Open **Models** and choose the model for tasks started inside BrowserPair.</Step>
  <Step title="Describe your task">Open **Chat**, choose the connected browser and describe a concrete result you want to verify.</Step>
  <Step title="Choose a Skill only if useful">A Skill is optional. Select one explicitly, or let your connected AI agent search for one when appropriate.</Step>
  <Step title="Review progress">Follow actions, user questions, confirmations and verified outcomes in **Activity**.</Step>
</Steps>

## How an active task behaves

The Agent Model plans from permitted browser observations; the Chrome extension carries out bounded steps. Your account's Standard or Developer mode applies throughout. Standard requests confirmation for sensitive operations; Developer skips mode-based confirmations. File upload and download are controlled by separate account file settings, enabled by default in both modes. Choosing a local file still requires your action.

Tasks may pause for missing information, an approval, a login challenge, a page that changed, or an uncertain result. BrowserPair does not automatically repeat an action whose effect may already have occurred. The final task history distinguishes verified outcomes from results that need review.

## Connected apps and Skills

An external AI app remains responsible for its own planning. Both direct BrowserPair Chat and external connections operate under the same browser account permissions. Skills are optional instructions and do not expand that authority.
