Use the BrowserPair dashboard when you want BrowserPair to coordinate planning, bounded execution, approvals, Skills, and task history for you.

<CardGroup cols={3}>
  <Card title="Choose the browser" icon="browser">Select the connected profile where the task is allowed to run.</Card>
  <Card title="Choose the websites" icon="globe">Define one or more explicit domains before execution begins.</Card>
  <Card title="Describe the outcome" icon="play">Tell BrowserPair what should happen; the task remains bounded by your settings.</Card>

## Choose how to start tasks

If you connect an external AI app such as ChatGPT or Claude, start tasks in that app. You do not need a BrowserPair Agent Model. The Activity page shows the connected app, a read-only first try, and shared task history.

If you connect your own Agent Model, use **Chat** to describe work in your own words. The first Agent Model becomes your account default. Accounts with neither path configured can choose either approach. Open **Settings → Models** to manage providers, **Permissions** for access settings, **Settings → Usage & analytics** for usage, and **Automations → Skills / Learning** for reusable workflows.

## Requirements

Before a managed task can run:

- at least one browser must be connected;
- at least one allowed website must be entered; and
- a **Agent Model** provider must be configured.

<Note>A Decision Model provider is optional. BrowserPair can still use bounded deterministic execution where available and escalate planning decisions to the Agent Model.</Note>

## Run a task

<Steps>
  <Step title="Open Chat">Describe the desired outcome in a new BrowserPair Chat conversation.</Step>
  <Step title="Open Task settings">Choose the browser and allowed websites. Multiple explicit domains are supported.</Step>
  <Step title="Choose a Skill or auto-match">Leave **Skill** on auto-match or select a compatible enabled Skill explicitly.</Step>
  <Step title="Keep the defaults or override them">Account-level Agent Model, Decision Model, trust threshold, observation policy, and execution limits are used unless you choose task-specific overrides.</Step>
  <Step title="Run and review">BrowserPair creates one durable task, surfaces approvals when needed, and records the final state in task history.</Step>
</Steps>

## Chat with your own model

When you configure an Agent Model, you can ask it to work through **Chat** in the BrowserPair App or from the Chrome side panel. A running task displays your request, model messages, steps, questions and current state in **Activity** and the side panel.

If the Agent Model needs something only you know, it asks a question and the task pauses for your reply. Your response or new instruction supplies context; it **does not grant new websites, capabilities or permission exemptions**. Review requested approvals in BrowserPair itself. BrowserPair records whether the final result was verified or needs review.

See [Agent Model + Decision Model](/agent-decision-model) and [Permissions](/permissions).
